# EMERGENT pitch deck source

Readable source for the standalone deck at `emergent.html`.

- `src/index.html` — slide markup
- `src/deck.css` — presentation styling
- `src/deck.js` — navigation and interactions
- `assets/` — artwork extracted from the standalone deck

Open `src/index.html` in a browser to preview. Keep the `assets/` folder alongside `src/`; image paths are relative. Edit the corresponding source file for content, styling or behavior. The standalone deck does not update automatically when source files change.
