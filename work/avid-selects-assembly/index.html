From Interview Selects to an Avid Review Assembly

Workflow automation: from script to screen

A script describes an edit in words; a timeline makes it visible and editable on screen. This workflow automates the translation between those two mediums. A document of interview selects provides the passages, speakers, sources and timestamps, and Python and pyavb help turn those instructions into an Avid review assembly.

In this experiment, an assistant editor provided the selects document and a short, manually assembled Avid sequence. An AI coding agent used the sequence as a reference and pyavb to build a separate review bin with the remaining passages in the document’s order. The editor could then open the timeline in Media Composer, review the placements and trim the results.

Why this surprised me

I’d tried to bridge this gap before using EDL, XML and AAF, without success. So I was surprised by how easily an agent could use pyavb to read the contents of an Avid bin and rewrite it into a working review bin. In this initial use, the generated bin opened in Media Composer without issue.

The reference is the guide

The reference sequence carries information a list of filenames does not: how the project’s grouped sources relate to the interviews, which camera and audio tracks are in use, and how the editor handles spacing and section slates. The workflow traces those relationships, checks the time origin for each interview part and preserves the requested order of the selects.

Where exact out points are unavailable, the first pass can estimate durations from the dialogue, subject to the editor’s direction. The result is a starting point for review; pauses, delivery and editorial timing still need a person’s attention.

What happened

In an initial production use, the editor confirmed that the generated bin loaded in Avid and reported that the clips and selects were correctly placed during review. The work felt magnitudes faster: it was as if I had been handed a general assembly by a junior editor, ready for me to review and refine. That is a personal impression from one use, not a controlled benchmark. Complete review of every generated cut and title, and compatibility across other projects and Avid versions, remain to be established.

Checking the handoff

The implementation used Python and pyavb, an independent library for reading and writing Avid bins. Before handoff, structural checks can verify track endpoints, source bounds and corresponding picture and audio edits. Playback, sync, media linking and title rendering still need to be checked in Media Composer.

The workflow report describes the process and its limitations. The original project-specific script and production materials are not included, so the report is a guide to adapting the approach rather than a ready-to-run tool.
