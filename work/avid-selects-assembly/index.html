From Interview Selects to an Avid Review Assembly

A practical workflow for AI-assisted documentary editing

Interview selects often start as a document: a set of passages, organized by topic, each with a speaker, a source and a timestamp. Turning those choices into a sequence means finding and placing each passage, one at a time, before the real work of shaping the edit can begin.

In this experiment, an assistant editor provided the selects and a short, manually assembled Avid sequence. An AI coding agent used that sequence as a reference to build a separate review bin with the remaining passages. The editor could then open the bin in Media Composer, review the placements and trim the results.

The reference is the guide

The reference sequence carries information a list of filenames does not: how the project’s grouped sources relate to the interviews, which camera and audio tracks are in use, and how the editor handles spacing and section slates. The workflow traces those relationships, checks the time origin for each interview part and preserves the requested order of the selects.

Where exact out points are unavailable, the first pass can estimate durations from the dialogue, subject to the editor’s direction. The result is a starting point for review; pauses, delivery and editorial timing still need a person’s attention.

What happened

In an initial production use, the editor confirmed that the generated bin loaded in Avid and reported that the clips and selects were correctly placed during review. The editor estimated the assembly work was roughly 10× faster. That is an informal observation from one use, not a controlled benchmark. Complete review of every generated cut and title, and compatibility across other projects and Avid versions, remain to be established.

Checking the handoff

The implementation used Python and pyavb, an independent library for reading and writing Avid bins. Before handoff, structural checks can verify track endpoints, source bounds and corresponding picture and audio edits. Playback, sync, media linking and title rendering still need to be checked in Media Composer.

The workflow report describes the process and its limitations. The original project-specific script and production materials are not included, so the report is a guide to adapting the approach rather than a ready-to-run tool.
