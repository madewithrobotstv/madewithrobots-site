Blender Map Workflow

Released October 2026 · Open source, MIT · Repository

A map is only useful if you can change it. Most relief maps arrive as a finished image, so the moment someone asks for a different extent, a closer view, or a different palette, the work starts over. This workflow builds the map as an editable Blender scene instead: terrain you can reshape, boundaries and labels as separate objects, and a camera rig on ordinary drivers rather than a custom add-on.

You drive it by asking an LLM to read the skill and follow it, in the same folder as your project. It fetches real elevation and boundary data, builds the scene in a fresh background Blender process, then reopens the saved file and checks its own work before handing anything back.

What it does

  • Builds terrain from real bare-earth elevation, in a projected metre CRS appropriate to the region
  • Keeps state boundaries, rivers, lakes, labels and the ocean as independent, editable elements
  • Separates display mesh density from shading detail, so finer relief survives as packed normal textures instead of geometry everywhere
  • Leaves missing data missing — it fails a coverage check rather than filling gaps with invented terrain
  • Records source URLs, acquisition dates and SHA256 hashes per map, and packs images so the scene still renders after you move it

How it is honest about itself

Saving a file is not proof the map is right, so the workflow treats them separately. After building, it reopens the saved scene in a fresh process and checks packed assets, drivers, terrain finiteness, feature counts, draping and framing, then a separate pass inspects the render. Failed checks are reported as failures.

It has been tested end to end on one configuration — Blender 5.2.2 LTS on macOS Metal. Other versions and platforms are expected to work but should run their own checks. The bundled data adapters cover U.S. sources (USGS 3DEP elevation, Census 2024 boundaries); other countries need an adapter, though the scene-construction principles travel.

Elevation: U.S. Geological Survey, 3DEP. State boundaries: U.S. Census Bureau, 2024 Cartographic Boundary Files. Map styling and the workflow itself: Made With Robots.

The agencies supply geographic data; this visualization does not imply their endorsement.
